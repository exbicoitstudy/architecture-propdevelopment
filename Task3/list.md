# Требования к безопасности внешних интеграций

**Требования к безопасности:**

- Шифрование данных при передаче (TLS 1.3): Обеспечивает конфиденциальность всех данных между PropDevelopment и партнёром — исключает перехват и подмену информации злоумышленниками
- Шифрование персональных/биометрических данных при хранении (AES-256): Гарантирует защиту персональных и биометрических данных на всех этапах хранения, даже в случае утечки или компрометации инфраструктуры
- Использование токенизации вместо передачи биометрии и номеров автомобилей: Снижает риски утечки критичных данных — при интеграции между системами используются уникальные идентификаторы вместо персональных данных
- Минимизация объёма передаваемых данных (только необходимое): Исключает несанкционированное распространение избыточной информации
- Централизованный аудит всех действий: Позволяет выявлять инциденты, проводить расследования
- DLP-контроль при передаче конфиденциальных данных: Помогает предотвратить несанкционированную передачу или выгрузку персональных данных
- Соблюдение законодательства по персональным/биометрическим данным: Все процессы соответствуют ФЗ-152 и профильным законам
- Изоляция внешних сервисов (через API Gateway): Устраняет риски несанкционированного доступа к внутренним системам PropDevelopment
- Регулярная ротация ключей доступа и сертификатов: Снижает риск компрометации — даже если ключи станут известны, их срок действия ограничен

**Протоколы аутентификации и авторизации:**

- OAuth 2.0 / OpenID Connect для авторизации пользователей
- JWT для каждого API-запроса между платформами
- mTLS для серверных интеграций
- RBAC/ABAC для определения прав пользователей и сервисов

**Организация взаимодействия:**

- Все запросы проходят только через API PropDevelopment и API партнёра
- Нет прямого доступа внешних сервисов к внутренним данным PropDevelopment
- Логирование и аудит каждого действия
- Все новые сервисы интегрируются через существующее мобильное приложение (без отдельных приложений для “умного дома”)
- Поддержка масштабирования и защиты от DDoS
